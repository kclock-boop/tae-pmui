# 품의 · AI 문서 워크스페이스

원본 DOCX 업로드 → 제목·사유 입력 → AI 작성 → 문단 편집 및 미리보기 → DOCX 다운로드.

## 실행

Node.js 22.13 이상에서 `npm ci`, `npm run dev`를 실행한 뒤 표시된 로컬 주소를 엽니다. 프로덕션 빌드는 `npm run build`입니다. Sites/Cloudflare Worker 환경용 Vinext 앱입니다.

## AI 연결

웹 화면 우측 위 **AI 연결 설정**에서 공개 HTTPS Base URL, 모델 이름, API 키를 입력합니다. 기본 Base URL은 `https://api.openai.com/v1`입니다. 서버가 `/chat/completions`에 `model`, `messages`를 POST하며 `choices[0].message.content`의 JSON을 검사합니다. 특정 공급자의 JSON 모드, 도구 호출, Responses API에 의존하지 않습니다. 로컬 주소/IP 주소는 호스팅 환경에서 허용하지 않습니다.

API 키는 React 메모리에만 유지하고 디스크·localStorage·쿠키에 저장하지 않습니다. 새로고침하면 문서와 키 모두 초기화됩니다. 원본 파일은 브라우저에서 처리되며 AI 작성 시 문서의 텍스트와 주변 문맥 및 입력 사유가 앱 서버를 거쳐 지정한 AI 공급자에게 전달됩니다. 공급자의 보관 정책은 별도로 확인해야 합니다. AI 호출 비용은 입력한 키의 계정에 청구됩니다.

## 양식 보존 방식과 지원 범위

JSZip으로 원본 ZIP 패키지를 읽고 `word/document.xml`, 머리글, 바닥글의 선택한 문단만 변경합니다. 다른 패키지 파일과 표 구조, 스타일, 이미지, 페이지 설정은 유지합니다. 수정한 문단의 텍스트는 첫 번째 run의 서식을 사용합니다. 한 문단 내 여러 글꼴/색상/부분 강조는 수정 후 그대로 유지되지 않을 수 있습니다. 줄바꿈은 `w:br`로 저장합니다. 긴 내용은 Word에서 표 높이나 페이지 수를 늘릴 수 있습니다.

일반 본문, 표 안의 텍스트, 머리글/바닥글 문단을 편집합니다. 빈 문단과 `{{항목}}`, `[작성]` 형태의 입력란을 AI 작성 대상으로 추천하고, 내용 편집에서 선택을 바꿀 수 있습니다. 스캔 이미지, 그림/복잡한 필드가 포함된 문단, 암호화 문서, DOC/HWP/PDF는 지원하지 않습니다. 변경 추적이나 전자서명이 포함된 원본은 사전 정리해 주세요. 전자서명은 파일 수정 시 무효화될 수 있습니다.

웹 미리보기는 docx-preview를 사용하고 스크립트를 허용하지 않는 iframe에 표시합니다. Word의 조판과 완전히 같지는 않습니다. 최종 문서는 Word에서 확인하세요. 10 MB 업로드, 50 MB 압축 해제 합계, 1,200개 문단 제한이 있습니다. 브라우저 새로고침 전 DOCX로 내려받아 주세요.

## 검증

`npm run test:core`는 예제 DOCX 로드, 문단 수정/재로드, 다중 run 입력란, 줄바꿈/특수문자, 미변경 ZIP 항목 보존 및 Chat Completions 계약/오류 처리를 확인합니다. 실제 유료 AI 호출은 API 키 입력 후 실행해야 합니다.
